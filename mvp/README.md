# Tenso Installer MVP

Aplicación de escritorio en Tauri 2, Rust y React para detectar launchers de
Minecraft y preparar la instalación de modpacks publicados por sus plataformas.

El primer corte detecta Modrinth App, Prism Launcher, PolyMC y CurseForge en
Windows. No modifica las carpetas de los launchers ni descarga contenido.

## Desarrollo

```powershell
npm install
npm run tauri dev
```
